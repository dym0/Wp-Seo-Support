A lightweight WordPress plugin to help manage essential SEO elements: custom meta titles, descriptions, slugs, robots.txt, and a dynamic XML sitemap.

== Description ==

**SEO Support** is a simple yet powerful SEO plugin designed to give you just the essentials:

- Add custom **SEO Title** and **Meta Description** to any post, page, or custom post type.
- **Edit the slug** directly from the post editor.
- Get **live character counters** and visual warnings when titles or descriptions are too long.
- Generate a valid **sitemap index** (`sitemap.xml`) with automatic support for all post types and taxonomies.
- Customize your **robots.txt** file from the admin panel.
- WooCommerce-compatible sitemap support for products and product categories.
- Lightweight, fast, and modular — no bloat.

== Features ==

- ✅ SEO title + description meta box with validation
- ✅ Custom slug editor + permalink preview
- ✅ Sitemap index and individual sitemaps for post types and taxonomies
- ✅ Robots.txt editor
- ✅ Clean code, no tracking, no ads
- ✅ Works well with block or classic editor

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/seo-support`
2. Activate the plugin through the **Plugins** menu in WordPress
3. Go to any post/page to find the **SEO Settings** meta box
4. Go to **Settings > SEO Support** for sitemap/robots configuration

== Frequently Asked Questions ==

= Will this plugin work with WooCommerce? =  
Yes, it includes support for `product` and `product_cat` in the sitemap.

= Does this plugin support Open Graph tags? =  
Not yet, but it’s coming in a future release.

= Can I submit the sitemap to Google Search Console? =  
Yes! Submit `/sitemap.xml` — it contains a full index of all public content types.

= Does it support multilingual plugins like WPML or Polylang? =  
Not officially, but the SEO fields work fine on translated posts.
